# November 26, 2026 — assumed versus actual synthetic command latency

Host LEGION; base commit c157716. Study source was written before running outcomes (SHA-256 `fb4f0b7ff2c930deecbd46f140a754cdd624d5c4b9f0d0c8bc93adca26633dbc`). These are synthetic authored geometries, not physical routes or a statistically independent sample.

## Implementation

`simulate_route(..., prediction_delay_steps=N)` accepts an explicit positive integer assumed FIFO length 1..10 only when ordered prediction is active and the actual delay is positive. An unequal estimate maintains its own request-history queue; actual displacement, observed progress, corner admission and terminal drain still use the actual plant. The consistency verifier independently reconstructs both queues and checks forecast position/heading, request application, elapsed time and observed metrics. The legacy report method/shape and exact-estimate results remain unchanged. The complete journey API passes the option only to approach prediction and labels the mismatch in compact reports. Terminal correction still knows actual delay; this is intentionally an approach-only uncertainty experiment. No sensor jitter, variable plant delay, collision, inertia or game input is modeled.

## Fixed comparison

From the Taxi root:

```powershell
python -B -m rift_taxi.synthetic_latency_mismatch --summary --out artifacts/NEW-mismatch.json
python -B -m unittest discover -s tests -p test_synthetic_latency_mismatch.py -v
```

Three new routes, two headings, two coupled speed/yaw/dt profiles and actual delays of 1, 3 and 5 steps (70–550 ms across profiles) yield 36 plant conditions. Each evaluates no prediction and near-stall prediction with assumed delay 1/3/5, for 144 complete journeys. Every case and failure is saved. Means are paired on common settled successes. All baseline and candidate runs share their actual plant conditions and bounds.

| Actual delay (steps) | No prediction | Assume 1 | Assume 3 | Assume 5 |

| 1 | 12/12 | 12/12 | 12/12 | 12/12 |
| 3 | 12/12 | 12/12 | 12/12 | 12/12 |
| 5 | 6/12 | 11/12 | 12/12 | 12/12 |

All 36 exact-estimate predictions settled, and 71/72 mismatched predictions settled. No candidate lost a no-prediction success, but severe underestimation lost one exact-estimate success. With actual delay 5 and assumed delay 1, the 11 common exact-estimate successes took 14.8536 s versus 6.5845 s for exact prediction (mean full-journey duty .81365 versus .89507). Overestimating actual delay 1 as 5 took 8.5950 s versus 4.8017 s on 12 common exact-estimate successes. Moderate errors may preserve arrival but reduce efficiency. These are descriptive model outcomes; do not infer a physical latency distribution or choose a new fixed horizon from them.
